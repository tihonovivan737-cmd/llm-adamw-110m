# Выполненные проверки

Дата: 23 сентября 2026. Среда проверки: Windows, Python 3.12, PyTorch 2.7.1 CPU. Полный запуск рассчитан на Linux/WSL2 с двумя RTX 3090.

- Все 9 автоматических тестов прошли. В частности, восстановление маленькой модели из чекпойнта даёт побитово те же веса, что и непрерывное обучение.
- Полная архитектура создана в памяти: 109 529 856 обучаемых параметров. Выполнены forward, backward, clipping и один шаг AdamW на последовательности длиной 16 на CPU. Loss конечный. Это проверка вычислений, не тест производительности целевого оборудования.
- По закреплённой версии загружен настоящий токенизатор TinyLlama: 32 000 токенов, EOS=2.
- Из настоящего FineWeb-Edu подготовлены 8192 обучающих и 1024 валидационных целевых токена. В этой сетевой проверке использовался уменьшенный shuffle buffer 32 и val_fraction 0.25.
- Маленькая модель со словарём 32 000 выполнила три шага на подготовленных настоящих данных, валидацию, сохранение чекпойнтов и генерацию из чекпойнта. Бюджет проверки 259 токенов специально включает неполный последний шаг. Качество текста этим не оценивается.
- Двухпроцессная проверка CPU/Gloo в этой Windows-среде не завершилась из-за ошибки подключения локального сокета и была остановлена. GPU/NCCL и BF16 на двух 3090 здесь не проверялись. Перед полным обучением выполните короткий запуск из README на целевой машине.

300 млн токенов здесь не скачивались и полный эксперимент не запускался. В архиве находятся исходники и инструкции, без датасета, весов, виртуального окружения и временных тестовых данных.
